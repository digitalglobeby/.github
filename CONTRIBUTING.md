# Contributing

## Gingham

Gingham ships as a binary framework: its repository holds the package, the
documentation and the releases, not the source, so it doesn't take pull
requests.

Issues are welcome: bug reports, questions and feature requests. For a bug,
the Gingham version (`GHTableView.version`), the system, the device and a
small piece of code that shows it make it quick to fix.

License keys and licensing questions go by email, not in issues:
**d.polikhranidi+gingham@gmail.com**. See
[LICENSING.md](https://github.com/digitalglobeby/Gingham/blob/main/LICENSING.md).

## Other repositories

Open-source repositories of Digital Globe say how to contribute in their own
README or CONTRIBUTING file. Where they don't, open an issue before a pull
request.
