# Security

If you find a vulnerability in one of Digital Globe's projects, please report
it privately by email, not in a public issue:

**d.polikhranidi+gingham@gmail.com** (subject: "Security")

Include the project and its version, the platform, what an attacker can do,
and the steps or code that show it. You'll get an answer by email, and the fix
is released as a new version before the issue is made public.
