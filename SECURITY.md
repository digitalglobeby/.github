# Security

If you find a vulnerability in Gingham or another Digital Globe project, please
report it privately by email, not in a public issue:

**d.polikhranidi+gingham@gmail.com** (subject: "Security")

Include the version (`GHTableView.version` for Gingham), the platform, what an
attacker can do, and the steps or code that show it. You'll get an answer by
email, and the fix is released as a new version before the issue is made
public.
